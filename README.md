HeartVision-VR
An immersive Virtual Reality application that enables users to explore a realistic 3D human heart in an interactive environment for learning anatomy and understanding cardiovascular structures.
❤️ HeartVerseVR

Overview
HeartVerseVR is an immersive Virtual Reality application that allows users to explore a realistic 3D human heart in a fully interactive environment. The project aims to improve anatomy learning by providing a 360° visualization experience.

Features

- 🫀 High-quality 3D human heart model
- 🥽 Virtual Reality support
- 🔄 360° heart visualization
- 🎮 Interactive navigation
- 📚 Educational anatomy experience
- 💻 User-friendly interface

 Technologies Used

- Unity 3D
- C#
- VR SDK
- Blender (3D Model)
- Visual Studio

Project Objectives

- Improve anatomy learning through VR.
- Provide an immersive educational experience.
- Help students understand heart structures in 3D.

Future Enhancements

- Voice-guided anatomy explanation
- Heart animation (blood circulation)
- Interactive quizzes
- AR mode support
- Multi-language support
